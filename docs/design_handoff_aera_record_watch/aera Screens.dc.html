2Build a workout with mixed time + distance steps

Each step ends on its own target, so time and distance can be mixed freely. This means moving from today’s fixed warmup · N×(work/recovery) · cooldown shape in intervalPlan.ts to an ordered PlanStep[] list, which the engine already runs. You write the plan on the phone; on the watch you can reorder steps or change a value with the bezel.
